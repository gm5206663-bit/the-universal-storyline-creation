# RELATIONSHIPS_TEMPLATE.md — knowledge firewalls

**Foundation docset v6.0 · core · universal.**
Who knows what, and since when. Author knowledge is never character knowledge.
If a character has not earned information on page, they do not have it — not
from rumour, not from intuition, not from prophecy fragments, and never from
the reader's bible.

This file is the serial's firewall registry (the Control Centre tracks the
same firewalls at project scale).

```
## The three leaks that kill a firewall

1. **Suspicion → fact.** Suspecting is not knowing; a firewall may not be
   downgraded by a character's guess.
2. **Reader-knowledge → character mouth.** The reader's canon memory never
   comes out of a character who has not seen it.
3. **Early gift.** Information arrives no earlier than the earliest valid
   change recorded in this table.

## Rules

- Every speaking character is checked against this registry before drafting
  (pre-draft gate, step 4).
- Moves are recorded the same turn the page earns them — a firewall updated
  after the chapter ships is a firewall that lied.
```
